# 中文 AI 写作痕迹模式库

> 收录中文场景下 LLM 写作的高频痕迹与改写对照。分四大类：
> **A. 词面触发**（脚本可自动扫描，10 类）· **B. 结构/语义触发**（需人工或模型，7 类）·
> **C. 中英夹杂**（警示）· **D. 中文特色补强**。模式只描述"动作"而非"字面"——
> 换一套词做同一个动作，仍算命中。
>
> 本库的触发词表与改写方向是**原创分类**，before/after 例句为**自撰**；模式类别借鉴
> 去 AI 味社区的公共认知，但具体分组、命名与正则均为自研。语料来源与许可见文末
> 「语料来源与许可」节。

## A 类 · 词面触发（自动可扫描）

每类含：触发词表、严重度（低 / 中 / 高）、改写方向、before→after 范例。
脚本扣分权重与严重度对应，见 `scoring-rubric.md`。

### A1 · 开头套话（命中即在文首加倍扣分）

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 在当今社会 / 在当今时代 | 高 | 直接删除，或换成具体场景 |
| 随着 XX 的发展 / 近年来，XX 日益 | 高 | 用具体时间替代 |
| 众所周知 / 毋庸置疑 / 不可否认 | 高 | 删除，或换成"多数人都……" |
| 伴随着 XX 的快速发展 | 高 | 改为"XX 出现后" |
| 在 XX 的背景下 | 中 | 改为具体语境 |
| 一直以来，XX 都 … | 低 | 改为"过去几年" |

**改写前 → 改写后：**
> 在当今社会，人工智能技术日益发展，众所周知已经渗透到各行各业。
> → AI 已经渗到各行各业。从客服到代码生成，几乎没有它不碰的角落。

---

### A2 · 转折/连接词滥用

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 此外 / 与此同时 / 不仅如此 | 中 | 句子直接接上，或用句号断开 |
| 然而 / 但是 / 尽管如此 | 低 | 多用句号分段，靠上下文连接 |
| 因此 / 综上所述 / 总而言之 | 中 | 删除，结论直说 |
| 一方面…另一方面… | 中 | 拆成两段 |
| 既…又…还… | 中 | 拆成两个动作 |
| 无可厚非 / 瑕不掩瑜 | 高 | 删除套话 |

**改写前 → 改写后：**
> 这一举措不仅提升了效率，此外还降低了成本。总而言之，效果显著。
> → 效率提上来了，成本也降了不少。

### A3 · 形容词堆砌 / 官腔

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 至关重要 / 举足轻重 / 不可或缺 | 高 | 删除或换成具体作用 |
| 深入探讨 / 深入分析 / 深入研究 | 高 | 改为"看一下"、"聊聊" |
| 核心 / 关键 / 精髓 / 要义 | 低 | 多数情况可删 |
| 高效 / 便捷 / 智能化 / 数字化 | 低 | 换成具体数字 |
| 高度重视 / 深入推进 / 扎实开展 | 高 | 改为"认真做了" |
| 积极探索 / 有效落实 / 持续优化 | 高 | 删除 |
| 凝聚共识 / 汇聚合力 / 协同推进 | 高 | 删除 |
| 全方位 / 多角度 / 立体化 / 全链路 | 中 | 删除或具体化 |

**改写前 → 改写后：**
> 我们高度重视用户体验，深入推进产品优化，全方位提升服务质量。
> → 我们改了改界面，把加载从 3 秒压到 800 毫秒。

### A4 · 结尾升华（影响最大，最易被认出）

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 让我们共同 / 让我们一起 | 高 | 删除或改成具体行动 |
| 未来可期 / 任重道远 | 高 | 删除 |
| 在 XX 的道路上不断前行 | 高 | 删除 |
| 为 XX 贡献力量 / 谱写新篇章 | 高 | 删除 |
| 砥砺前行 / 扬帆远航 | 高 | 删除 |
| 展望未来，XX 将 … | 中 | 改为具体计划 |

**改写前 → 改写后：**
> 让我们共同期待，在数字化转型的道路上不断前行，谱写新篇章。
> → 下个季度重点做两件事：把审批从 1 天压到 2 小时，把月报改成周报。

### A5 · 排比 / 三段式 / 伪对仗

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| X、X 与 X / X、X、X | 低 | 多用两项或四项 |
| 一是…二是…三是… | 中 | 改成自然过渡 |
| 既…又…还… | 中 | 拆句子 |
| 这不仅…也…更… | 高 | 砍掉中间环节 |
| 从 X 到 Y，从 X 到 Y | 中 | 删 |

**改写前 → 改写后：**
> 这不仅体现了技术创新的力量，也彰显了人文关怀的温度，更展示了企业文化的深厚底蕴。
> → 背后是技术团队和文化团队一起搭的。

### A6 · 营销体 / 互联网黑话

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 赋能 / 加持 / 引爆 / 破圈 | 高 | 改为具体动词 |
| 打造 / 构建 / 重塑 | 中 | 看情况，多数可删 |
| 一站式 / 全链路 / 闭环 | 中 | 改为具体描述 |
| 抓手 / 打法 / 颗粒度 | 高 | 删除或换说法 |
| 底层逻辑 / 顶层设计 | 高 | 删除 |
| 沉淀 / 拉通 / 对齐 | 中 | 改为大白话 |

**改写前 → 改写后：**
> 我们致力于打造一站式全链路解决方案，赋能业务增长。
> → 我们做了一个工具，把 5 个流程合到一个页面上。

### A7 · 模糊归因 / 假权威

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 专家指出 / 业内人士表示 | 高 | 给具体名字 + 出处 |
| 据相关研究表明 / 大量数据表明 | 高 | 给出具体研究 / 数字 |
| 有学者认为 / 专家普遍认为 | 高 | 删除或具体化 |
| 众所周知 / 大家普遍认为 | 中 | 删除 |

**改写前 → 改写后：**
> 专家指出，AI 在医疗领域具有广阔的应用前景。
> → 斯坦福 2024 年的报告显示，AI 辅助诊断在皮肤癌识别上准确率比医生高 5 个百分点。

### A8 · 伪深度分析（"是 XX 的体现 / 证明 / 象征"）

|---|---|---|
| 这是 XX 的体现 / 证明 / 象征 | 高 | 直接说事实 |

### A11 · 文学 / 赛博痕迹（写诗、散文、文艺文案时高频）

> 大模型写文艺内容时的招牌动作：往里面塞科学词、造"赛博意象"、报出没有出处的精确数字。

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| 熵增 / 坍缩 / 密钥 / 多巴胺 / 辣椒素（用于写诗、写散文） | 高 | 删掉，换成具体的身体感受 |
| 泪腺的剖白 / 流动的琥珀 / 鎏金的基因序列（赛博意象堆砌） | 高 | 删意象，写具体场景 |
| 褶皱的褶皱 / 古老的密码（自造抽象短语） | 中 | 换成大白话 |
| 凌晨 X 点 X 分 / 第一千只羊 / 第 X 颗扣子（无出处精确数字） | 中 | 数字要么有来源，要么虚化 |
| "某某的遭遇，像一面某某的镜子，映照出/折射出某某的共同困境" | 高 | 删模板，写一个具体的人 |
| "A 告诉 B，有时候，打破 C"（套路叙事句） | 中 | 改成真实对话 |

**改写前 → 改写后：**
> 凌晨三点十七分，多巴胺的潮汐里，我听见泪腺开始剖白。
> → 那晚我没睡着。凌晨三点多，窗外有车开过去，声音很响。

### A12 · 词汇塌缩（同义挤占、画面感丢失）

> 大模型把中文词汇压到"中位数"：高频词吃掉低频词，具体动词塌成上位词，画面感消失。

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| "但是" 挤占 然而 / 不过 / 只是 / 却 | 中 | 偶尔换回 却 / 不过 |
| "非常" 挤占 颇 / 甚 / 极 / 煞是 | 中 | 有画面感的场合换回具体程度词 |
| "了解" 挤占 知晓 / 晓得 / 洞悉 | 低 | 书面语可换回 |
| 踱 / 踉跄 / 徜徉 → 全变"走"；窜 / 掠 / 奔 → 全变"跑"；啃 / 咂 / 抿 → 全变"吃/喝" | 中 | 保留有画面感的具体动词 |
| 句末 呢 / 啊 / 呗 / 嘛 被克制掉（中文变"干"） | 低 | 口语场合恢复语气词 |

**改写前 → 改写后：**
> 他瘦削地走在街上，非常了解这件事。
> → 他踱着步子，鞋跟敲着地面。这件事他门儿清。

### A13 · 社交腔 / 过度亲和（聊天、私信、相亲场景高频）

> 大模型模仿"贴心"时露出的破绽：秒回热情、机械接话、上人生格言、连环提问。

| 触发词/句式 | 严重度 | 改写方向 |
|---|---|---|
| "睡眼惺忪的你一定很可爱"（对陌生人过度亲昵） | 高 | 删掉，正常打招呼 |
| "一听名字就感觉你很有气质"（空泛赞美） | 高 | 换成具体的、可验证的观察 |
| "苦是暂时的，人生都是先苦后甜"（心灵鸡汤万能回复） | 高 | 删掉，接住对方的具体情绪 |
| "哇，这几个爱好也太健康了吧！"（夸张反应词） | 中 | 平实回应 |
| 先夸张赞扬 → 搬自己经历 → 针对性提问（无论文题都接上话） | 中 | 砍掉三段式模板 |
| 大量感叹号 + 波浪号"～" + 语气词"呀/哦/呢"堆砌 | 中 | 克制标点，自然断句 |

**改写前 → 改写后：**
> 听说你最近加班多～好忙呀！我其实也常常加班，你一般几点下班呢？
> → 加班多确实熬人，你现在好点了吗？

## B 类 · 结构/语义触发（人工或模型识别，脚本只给提示）

### B1 · 句式单一化
- 每个段落长度几乎相同
- 每段以"X。"短句机械收尾
- 全文都是"是 XX 的"结构
- 全文都是动宾结构（"提升 X、降低 Y、增强 Z"）

### B2 · 段落对称结构
- 全文每段都是"观点 + 论证 + 例子 + 总结"四件套
- 每一段都强行形成"总分总"

### B3 · 滥用标题层级
- 一段话一个标题，标题像"四字成语"
- 标题全部加装饰符号或 emoji
- 标题全部粗体加冒号

### B4 · 总结段落"放之四海而皆准"
- 结尾段像万能模板："未来还需继续努力，不断完善"
- 通用的三个"展望"项

### B5 · 缺乏具体细节
- 没有数字、时间、地点、文件名、版本号
- 全是抽象概念堆砌
- 没有真实的人名、公司名、产品名

### B6 · 缺乏个性化声音
- 没有"我"、"我们"的具体视角
- 没有不确定性表达（"我不太确定"、"可能"、"还在想"）
- 没有吐槽、自嘲、口语化断句
- 像新闻通稿 / 维基百科

### B7 · 标点滥用
- 过多破折号「——」
- 过多感叹号「！！！」
- 过多问号「为什么？为什么？为什么？」
- 中英混排但空格混乱（"iOS 设备""iOS 设备"混用）

## D 类 · 中文特色补强
英文通用指南对中文特色覆盖不足，本 skill 额外强化五类高频出现、读者最反感的痕迹：

1. **官腔八股**（高度重视、深入推进、扎实开展）
2. **互联网黑话**（赋能、抓手、底层逻辑）
3. **四字成语串**（博大精深、源远流长）
4. **结尾升华段**（让我们、谱写新篇章）
5. **模糊归因**（专家指出、业内人士表示）

实际中文写作中，**官腔 + 互联网黑话 + 模板口水**这三类出现频率最高。

## 成稿硬禁令（命中任一项不得交稿，`python -m src.cli` 强制清零）

禁的是**修辞动作**而非字面，换一套字做同一动作仍算命中。

- **翻案腔**：先立读者本没有的误解、再推翻给下文抬价。「不是……而是……」「并非……而是……」
  「不在于……而在于……」「与其说……不如说……」「表面……实际……」「看似……实则……」及其变形
  （「不是 A，是 B」「你以为……其实……」「回头才发现」「说到底」「答案恰恰相反」
  「A 不重要，重要的是 B」）。判断从正面下，先给判断再给依据。
- **三项以上同构排比**：两项为限，第三项换说法或删。
- **给抽象名词配具体动词抒情**：时间不会保管细节，焦虑不会显出形状。写具体事物时不受影响。
- **动词名词化**：「进行了优化」→「改顺了」，「实现了增长」→「多挣了多少」。
- **破折号** `—` `——` `–`：一律不用。
- **冒号** `：` `:`：仅允许引出人物直接原话；「一句话总结：」「核心是：」等提示性冒号禁止
  （网址、代码、机器字段除外）。
- **「说白了」「说穿了」「先说结论」**：不用。
- **洞察路标**：「更微妙的是」「还有一层」「只说对了一半」「值得注意的是」「需要指出的是」
  「从某种意义上说」不做段落或句子路标。
- **商业 / 模型黑话**：绝对禁词（赋能、抓手、闭环、底层逻辑、顶层设计、降本增效、全链路、
  组合拳……）；语境词（沉淀、颗粒度、对齐、打法……）需结合本义判断。
- **非虚构借喻包装**：不用仓库、抽屉、温度、死亡、坍塌、浪潮、钥匙、底座等借喻包装抽象概念。
- **结尾升华**：「让我们共同……」「未来可期」「谱写新篇章」「任重道远」一律删除或换成具体计划。
- **模板口水**：「大家好，我是 XX」「本文将从 N 个方面阐述」「希望本文对您有所帮助」
  「以上就是全部内容」删除。
- **原话命中禁令**：转述或省略，不靠引号保留。

## 两种语域（Voice register）

同一个 skill，两种输出场合，语气必须切换。

**聊天（对话框，不涉及文件产出）**
像一个朋友说话：平和、克制的一点点热情。可以带"我"的视角、偶尔吐槽、
留一点不确定。句子短，像真人打字。

- 推荐：直接、具体、有立场、允许不完美
- 避免：堆排比、上价值、喊口号、秒回式热情

**写文件（txt / word / python / pdf / md 等任务产出）**
好好思考，冷静克制，不卖弄词语。读者是来拿结果的，不是来感受情绪的。

- 推荐：判断先行、给依据、数字与出处、删掉形容词
