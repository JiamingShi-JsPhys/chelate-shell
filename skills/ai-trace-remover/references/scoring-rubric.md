# 评分规则（Scoring Rubric）

> 定义"人话指数"0–100 的算法与等级，以及交稿门槛。`python -m src.cli`（词面 + 硬禁令共用本规则；
> 单一 CLI 同时输出两类结果，无需再跑另一个脚本）。

---

## 一、人话指数（0–100，100 = 完全人话）

由两部分扣分叠加而成：

```
total_deduction = lexical_deduction + structural_deduction
score           = clamp(100 - total_deduction, 0, 100)
```

### 词面扣分 lexical_deduction
- 对 `ai-patterns-zh.md` 的 A1–A10 模式逐条正则命中，每次命中按模式基础分 `penalty` 计。
- **位置加权**：A1（开头套话）命中在**前 20% 行**、A4（结尾升华）命中在**后 20% 行**，
  单次基础分 ×1.5。
- **重复衰减**：同一模式 + 同一字面命中，第 N 次出现计入 `min(N, 3)` 倍基础分
  （最多按 3 次计，避免重复词刷分）。

### 结构扣分 structural_deduction（仅当全文 ≥ 5 行时生效）
| 结构问题 | 扣分 |
|---|---|
| 破折号 `——` 数 ≥ max(3, 字符数/200) | -5 |
| 出现 `!!!` 或 `!!` 累计 ≥ 3 | -3 |
| 全文无任何阿拉伯数字（无具体细节） | -12 |
| 全文无第一人称 `我/我们`（无说话人） | -8 |
| emoji 数 ≥ 3 | -min(9, (emoji数-2)*3) |

### 等级
| 分数 | 等级 |
|---|---|
| 85–100 | 人话 |
| 70–84 | 微 AI 味 |
| 50–69 | 中度 AI 味 |
| 30–49 | 重度 AI 味 |
| 0–29 | 完全 AI 体 |

## 二、英文稿（仅词面评分，不套人话指数）

英文稿运行同一引擎，使用 `ai-patterns-en.md` 的 E 系列模式（与 24 类编号对应），
输出 `ai_taste_score`（0–100，越高越 AI 味，与中文"人话指数"方向相反，避免混淆）。
**交稿判定的"人话指数"门槛只对中文稿生效**；英文稿以词面命中清零 + 结构提示为准。

---

## 三、改写优先级（同分先改影响最大的）

`A4 结尾升华 → A3 官腔 → A6 黑话 → A1 开头套话 → A7 模糊归因 → A8 伪深度`
→ `A9 假大空 → A2 连接词 → A5 排比 → A10 模板口水`。
（结尾段最容易被读者一眼认出是 AI，故排第一。）

---

## 四、交稿门槛（四项全过才交，缺一项不交稿）

1. **硬禁令为零** —— `python -m src.cli` 报出的必须清零项全部清完。
2. **人话指数 ≥ 85**（中文稿）且"声音五条"（见 `revision.md`）全部达标。
3. **长稿（≥1200 字）另走完七遍人工改稿**（`revision.md`）。
4. **冷读一遍，只回答四句**：
   - 哪里让我相信作者确实知道这件事？
   - 哪里让我愿意继续读？
   - 哪一段像模型在完成写作任务？
   - 文章在哪一句已经结束？

> 脚本分数只负责词面与结构，**不替代人工判断**。分数到了 85 但声音五条没过，仍要改。

---

## 五、失败兜底

- 脚本报"文件不存在 / 无法读取"：Word/HTML/PDF 先另存或抽取为 `.md`/`.txt`；
  粘贴文本先写入临时文件再跑。仍失败则弃用脚本，按硬禁令全文搜索冒号、破折号、
  "不是……而是……"、赋能/抓手/闭环，逐条人工清零。
- 专业必需术语被判黑话（电路闭环、化学沉淀、排版对齐）：按本义判断，本义保留
  并在报告里注明；换不成具体描述就宁可啰嗦也不用黑话。
- 改写后人话指数不升反降：多半是只删词没补声音，按"声音五条"逐条补；仍不行
  回到扣分最高的命中类别整段重写，不做逐句替换。
