Chelate Shell — Third-Party Licences
====================================

Chelate Shell's own source is released under the MIT License (see the
top-level LICENSE file, Copyright (c) 2026 Jiaming Shi). The 20 skill
adapters under skills/ are MIT as well.

The adapters call third-party Python libraries at run time. None of those
libraries is vendored here: no third-party source is copied into this
repository. They are installed by the user, and each package ships its own
licence text. This document records what the shipped code references, the
licence class of each library, and the attribution a permissive licence asks
us to preserve.

Policy
------
Every runtime dependency is under a permissive licence: MIT, BSD-family,
Apache-2.0, or the Matplotlib licence (BSD-compatible, PSF-based). A
copyleft library (GPL, AGPL, or any other strong-copyleft licence) is not
accepted on the runtime path without a deliberate review recorded in this
file.

PyMuPDF is not a dependency. Its licence is AGPL-3.0 and nothing in the
shipped tree imports it. The test suite builds its sample PDF with pypdf;
when PyMuPDF happens to be installed the test prefers it, because the
pypdf-only fixture carries no font metrics and pdfminer then emits one glyph
per line. That is a test-fixture choice, not a runtime dependency.

Maintenance
-----------
When a library is added to a skill's manifest or requirements, add its row to
the runtime table above and its copyright notice below it. Keep the licence
class permissive: introducing a copyleft dependency needs a review and an
update to the policy paragraph, not just a table row.
