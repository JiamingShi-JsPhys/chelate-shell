Chelate Shell — Third-Party Licences
=======================================

Chelate Shell's own source code is released under the MIT License (see the
top-level LICENSE file, Copyright (c) 2026 Jiaming Shi).

This project is composed of a thin orchestrator plus 18 skill adapters (none of
which remain skeletons in v1.2.0). The
adapters themselves are MIT, but several of them invoke third-party Python
libraries. This document lists every third-party library the release
references, its actual licence class, and its copyright header, so that the
license compliance chain is auditable.

Every third-party dependency listed here is a *permissive* licence
(MIT / BSD-family / Apache-2.0). No component in this release links a
copyleft library (GPL, AGPL, or any other strong-copyleft licence). The
previous AGPL component (PyMuPDF) was removed in v1.1.1.

Licence classes involved
------------------------
  MIT            — permissive
  BSD-2-Clause   — permissive
  BSD-3-Clause   — permissive
  Apache-2.0     — permissive (grant of patent rights; compatible with MIT)

degrade to UNVERIFIED when the library is absent, so neither is bundled or
vendored in this repository.

Compliance note: permissive licences require only that the copyright and
licence notices of each library be preserved with the distribution. The
copyright headers for each library are reproduced below.

Maintenance
-----------
If a new third-party library is added to any skill's manifest dependencies,
append its entry to the table above and its copyright header to this section.
The licence class of every entry must remain permissive; introducing a
copyleft (GPL/AGPL) dependency requires a deliberate legal review and is not
permitted by the project's pure-permissive distribution policy.
